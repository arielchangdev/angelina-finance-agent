# Red Team Automation 系統 - 客戶部署指南

## 📋 收到部署包後的操作步驟

### 步驟 1: 解壓縮部署包
1. 將收到的 `RedTeamAutomation-v1.0.0.zip` 解壓縮到任意目錄
2. 確保解壓縮後的資料夾有完整的檔案結構

### 步驟 2: 檢查系統需求
- **記憶體**: 8GB RAM (建議 16GB+)
- **磁碟空間**: 20GB 可用空間 (建議 50GB+)
- **作業系統**: Windows 10/11, Ubuntu 20.04+, CentOS 8+, macOS 10.15+
- **網路**: 穩定的網際網路連線 (用於下載 Docker 映像檔)

### 步驟 3: 一鍵安裝

#### Windows 用戶
1. **以管理員身分執行**
2. **雙擊 `啟動系統.bat`**
3. **等待自動安裝完成** (約 10-20 分鐘)

#### Linux/macOS 用戶
1. **開啟終端機**
2. **切換到解壓縮目錄**
3. **執行安裝腳本**:
   ```bash
   ./啟動系統.sh
   ```
4. **等待自動安裝完成** (約 10-20 分鐘)

## 🌐 系統存取

安裝完成後，開啟瀏覽器訪問以下網址：

### 主要介面
- **🔗 API 文件**: http://localhost:8000/docs
  - 這是系統的主要操作介面
  - 可以執行所有紅隊測試功能
  - 無需額外認證

### 監控介面
- **📊 系統監控**: http://localhost:3000
  - 帳號: `admin`
  - 密碼: `admin123`
  - 可以查看系統效能和運行狀態

### 管理介面
- **🗄️ 資料庫管理**: http://localhost:8081
  - 帳號: `admin`
  - 密碼: `admin123`
  - 可以查看和管理測試資料

## 🛠️ 常見問題

### Q: 安裝失敗怎麼辦？
A: 
1. 檢查網路連線是否穩定
2. 確認系統需求是否滿足
3. 以管理員/root 權限重新執行
4. 查看錯誤訊息並聯繫技術支援

### Q: 無法存取系統介面？
A: 
1. 確認所有服務都已啟動: `docker-compose ps`
2. 檢查防火牆設定
3. 確認連接埠 8000, 3000 沒有被其他程式佔用
4. 等待服務完全啟動 (約 2-3 分鐘)

### Q: 系統運行緩慢？
A: 
1. 檢查系統資源使用情況
2. 確保有足夠的記憶體 (建議 16GB+)
3. 關閉不必要的其他程式
4. 考慮增加系統資源

### Q: 如何停止系統？
A: 
```bash
# 停止所有服務
docker-compose down

# 完全清理 (包含資料)
docker-compose down -v
```
